# 📩 SMS Spam Detection Using Machine Learning & NLP

## 📌 Project Overview
This project focuses on building a Machine Learning model that can automatically classify SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing techniques. The system helps in filtering unwanted messages and improving communication efficiency.

## 🚀 Features
- Text preprocessing (cleaning, tokenization, stopword removal, stemming)
- Exploratory Data Analysis and visualization
- Feature extraction using TF-IDF Vectorization
- Model training using Multinomial Naïve Bayes and other classifiers
- High accuracy spam classification
- Real-time prediction support

## 🛠️ Technologies Used
