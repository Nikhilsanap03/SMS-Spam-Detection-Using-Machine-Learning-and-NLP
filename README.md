# 📩 SMS Spam Detection Using Machine Learning & NLP

## 📌 Project Description

This project builds an intelligent SMS Spam Detection system using Natural Language Processing and Machine Learning techniques. The model classifies text messages as Spam or Ham by performing data cleaning, preprocessing, feature extraction using TF-IDF, and training classification algorithms such as Multinomial Naïve Bayes. The trained model enables accurate and real-time spam message prediction.

---

## 🚀 Features

✅ Text preprocessing (lowercasing, tokenization, stopword removal, stemming)
✅ Exploratory Data Analysis and visualization
✅ Feature extraction using TF-IDF Vectorization
✅ Machine Learning model training and evaluation
✅ High accuracy spam classification
✅ Model saving using Pickle for deployment
✅ Real-time SMS prediction support
